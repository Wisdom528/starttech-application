\# StartTech Application



\## Overview



StartTech Application is a cloud-native application consisting of a React frontend and a Golang backend.



\## Technology Stack



\* Frontend: React

\* Backend: Golang

\* CI/CD: GitHub Actions

\* Containerization: Docker

\* Cloud Platform: AWS EC2



\## Project Structure



\* frontend/ - React application

\* backend/ - Golang API

\* .github/workflows/ - CI/CD workflows



\## CI/CD Pipeline



Frontend CI/CD:



\* Install dependencies

\* Build React application



Backend CI/CD:



\* Run Go dependency checks

\* Execute tests

\* Build Docker image



\## Deployment



The application is deployed using Docker containers on AWS EC2.
